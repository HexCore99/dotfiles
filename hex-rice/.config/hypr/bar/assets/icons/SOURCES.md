# Icon sources

Lucide SVGs are vendored unchanged from https://github.com/lucide-icons/lucide
at commit `20aef31db93fe4d9f398dbb15b120d99c48eef95`. The upstream license is included in `lucide/LICENSE`.

The Arch Linux logo is from https://github.com/simple-icons/simple-icons
at commit `c71c69e3a27e4436936b831c72643e6513b9f49b`. Its CC0 license is in `brands/LICENSE`.
Arch Linux is a trademark of its respective owner.

The bar loads these local files and tints them in QML. No runtime download or
icon font is needed. Replace the SVG files here to choose another icon set.

`lucide/sun.svg` is a locally drawn brightness symbol using the same 24px,
2px-stroke style; it is not part of the pinned upstream download.

`lucide/image.svg` and `lucide/x.svg` are local drawings in the same stroke style
for the wallpaper panel; they are not part of the pinned upstream download.
